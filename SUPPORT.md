# Support

Start with the [setup guide](docs/GETTING_STARTED.md) and [troubleshooting](docs/TROUBLESHOOTING.md).

- **Something is broken:** [submit a bug report](https://github.com/katsudc/katsu-tracker-releases/issues/new?template=bug_report.yml).
- **An idea for the app:** [request a feature](https://github.com/katsudc/katsu-tracker-releases/issues/new?template=feature_request.yml).
- **A sensitive security issue:** follow [Security](SECURITY.md).

Include the app version, your Windows version and enough steps to reproduce the problem. Screenshots should have personal player information removed. Do not post credentials, tokens, private keys or unreviewed logs.

This repository hosts public releases, documentation and issue tracking. Source code has not been published here yet.
