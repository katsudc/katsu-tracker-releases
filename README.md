# katsu's Tracker

Windows indirmeleri ve otomatik güncellemeler.

[Son sürümü indir](https://github.com/katsudc/katsu-tracker-releases/releases/latest/download/Katsu-Tracker-setup.exe)

Eski taşınabilir sürümden geçiyorsan önce tracker'ı kapatıp kurulum dosyasını bir kez çalıştır.
Yeni sürümler arka planda indirilir. Hazır güncellemeyi VALORANT kapalıyken kurabilir veya tracker'ı sonraki açışında yükletebilirsin.
Kullanıcı ayarları uygulamanın veri klasöründe korunur.

KDA, HS ve WR değerleri erişilebilen en fazla son 20 rekabetçi maça aittir; Tracker Score veya genel toplam değildir.

Bu depo yalnızca dağıtım içindir. Güncelleme paketleri uygulamanın doğruladığı imzayla yayımlanır.

Temel proje: [ruwiss/valorant-tracker](https://github.com/ruwiss/valorant-tracker), MIT lisansı. Özgün telif bildirimi kurulumda ve release içindeki LICENSE.txt dosyasında korunur.
Riot Games veya Tracker Network ile bağlantılı değildir.
