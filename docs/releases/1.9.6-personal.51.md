# Companion Suite — 1.9.6-personal.51

## Faster everyday controls

- Open pages and actions with Ctrl+K while the tracker has focus.
- Restore the existing window and control streamer mode, Spike Timer and instalock from the Windows tray.
- Choose temporary Safe Mode after an unclean exit and preview a sanitized diagnostic ZIP before saving it.
- Fix the Windows freeze when selecting **Start normally**: optional overlay creation now runs outside the synchronous IPC handler.

## Your personal performance

- Personal coach comparisons, agent/map drilldowns, lightweight trends and Rank Journey.
- Available-history recap images and optional session goals with neutral reminders.
- Analysis uses your own accessible Competitive matches, currently up to 20. Missing RR, opening-event or other fields remain unavailable; recaps do not claim to cover an entire Act.

## Local player tools

- Portable lineup packs with import previews and Skip / Replace / Keep both options.
- Optional saved-lineup filtering when map, your agent and side are all known.
- Match/reference notes, optional timestamp-only moment marking, crosshair codes and sensitivity/eDPI profiles.
- Local account preferences and confirmed privacy controls. Notes and markers are not uploaded; moment marking records no media.

## Compatibility

Existing preferences and .46 data formats remain compatible. The visual Spike detector, Fullscreen Game Bar bridge/widget, Spotify backend and updater implementations are preserved. No opponent-performance service or gameplay input automation was added.

The normal-start fix was tested locally and confirmed by the user before this release. Signing keys, credentials and private diagnostic files are excluded from the repository and update package.
