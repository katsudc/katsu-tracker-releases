# Brand assets

The project uses graphite, off-white and a restrained rose accent.

| Color | Value |
| --- | --- |
| Background | `#0d1119` |
| Graphite | `#172132` |
| Rose | `#ff8eae` |
| Off-white | `#e6edf5` |

## Artwork

- [Wide cover](assets/hero.png) — project landing-page artwork.
- [Square brand mark](assets/brand-mark.png) — an original sculptural K for media use.

<img src="assets/brand-mark.png" width="240" alt="Graphite K with a rose illuminated edge">

These two artwork assets were generated using the built-in image-generation tool. Application previews are captured from the actual interface with sample player and music data. VALORANT content artwork visible in those previews belongs to its respective owners.

## Final generation prompts

<details>
<summary>Wide cover</summary>

```text
Use case: ads-marketing
Asset type: professional GitHub README hero banner for an existing Windows application.
Primary request: Create a premium wide horizontal brand cover for "katsu's Tracker", a minimal VALORANT desktop companion. This is brand artwork, NOT an application screenshot. Use an original abstract architectural composition, an angular sculptural letter K cut from matte graphite metal, one restrained rose-pink illuminated seam, subtle fine technical grid lines and beautiful soft shadows. Existing brand palette: near-black #0d1119, graphite #172132, rose #ff8eae, cool off-white #e6edf5. Elegant editorial art direction, restrained esports atmosphere, crisp and polished, no weapons, no game characters, no Riot or Spotify logos, no neon clutter. Very wide 3:1 landscape composition, calm negative space around copy. The sculptural K occupies the right third. Place very large, perfectly legible modern white typography on the left. Text (verbatim): "katsu's Tracker". Below it in much smaller clean typography: "Your match. In focus.". A tiny uppercase label above: "WINDOWS DESKTOP COMPANION". No other text, no fake statistics, no UI panels, no watermark. High-resolution finished marketing artwork suitable for a GitHub project cover.
```

</details>

<details>
<summary>Square mark</summary>

```text
Use case: stylized-concept
Asset type: square brand artwork for the media kit of katsu's Tracker, matching a premium GitHub cover.
Primary request: Create a perfectly centered original sculptural uppercase letter K standing upright, carved from deep matte graphite metal with one precise restrained rose-pink illuminated bevel. Elegant premium gaming-software brand image, minimal studio photography / realistic 3D render. Near-black #0d1119 backdrop, cool grey edges, rose #ff8eae light, soft floor reflection, extremely polished material quality. The K is highly legible as a standalone silhouette and occupies about 65% of the square canvas, ample safe margins on all sides. Subtle architectural echoes in the far background, no visual clutter. Square composition, front three-quarter view, clean enough to read as a small thumbnail. No UI, no statistics, no words, no other letters, no Riot/VALORANT/Spotify logos, no people, no guns, no watermark. This is original promotional brand art, not an application screenshot.
```

</details>
